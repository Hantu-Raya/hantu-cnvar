Method

  • Harness r3_20261011/bench/harness3.py. Two ABBA sets: Hantu's vs Sqooky, then Hantu's vs CompyLock. Each run kills the game, installs the frozen gameinfo, launches through dead.bat with -vconsole -insecure and plays the demo via VConsole.
  • Hantu's = the installed gameinfo.gi (md5 c9281b77) with perf_r3.cfg. For the other arms an empty perf_r3.cfg neutralised the auto.cfg hook.
  • Both upstream files were checked against their main HEAD on the run date and matched byte for byte.
  • The original gameinfo and perf_r3.cfg were restored after each set and verified.

Limits

  • Two pairs per opponent. The formal 95% CIs on the FPS difference still span zero, though the direction held in all four pairs.
  • Hantu's includes perf_r3.cfg; a gameinfo-only Hantu's arm was not measured.
  • Upstream extras were not installed (Sqooky's pak54 and base_convars.txt; CompyLock's VPKs and video.txt).
  • Image quality differs. Hantu's turns off direct lighting, skybox, fog and decals and caps textures at 128, so part of the lead comes from rendering less.
  • CPU-bound spectator demo; live matches add server and input work.
