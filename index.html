Before you switch

The configs do not look the same

Hantu's turns off direct lighting, the skybox, fog and decals and caps textures at 128. Part of its lead comes from drawing less, so compare the visuals as well as the numbers.

  • Hantu's was tested with its perf_r3.cfg. The other two were tested with their gameinfo.gi only; Sqooky's addon pak and base_convars.txt and CompyLock's VPKs and video.txt were not installed.
  • Two pairs per competitor is a small sample. The direction held in every pair, but the 95% confidence interval on each difference still includes zero.
  • Sqooky and CompyLock overlap (85.4–94.0 FPS) and cannot be ranked against each other.
  • The scene is a CPU-bound spectator replay. Live matches add server and input work.

How it was measured
  • Demo 110239551 from tick 138245, 300 seconds per run, 1600×900 windowed, same installed mods for every run.
  • Two sets in ABBA order: Hantu's, Sqooky, Sqooky, Hantu's; then the same with CompyLock. Each run closed the game, installed that config's gameinfo.gi, relaunched and drove the replay over the developer console.
  • For the competitor runs an empty perf_r3.cfg replaced Hantu's, so none of its settings applied.
  • FPS = frames counted by the profiler's FrameTotal row ÷ wall-clock seconds. Client 6774 no longer reports a Present counter, so this is a profiler count, not an independent present measurement. CPU = process CPU time ÷ wall-clock seconds, where 1.0 is one fully busy logical core.
  • The original gameinfo.gi and perf_r3.cfg were restored and checksum-verified after each set.
